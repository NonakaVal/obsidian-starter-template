Guia de Instalação

Between Notes — Starter Template para Obsidian

10 minutos Iniciantes 3 passos
1

Instalar o Obsidian

1.1 Baixar o Obsidian

  1. Acesse o site oficial: obsidian.md
  2. Selecione a versão para seu sistema operacional
Gratuito para uso pessoal. Não é necessário criar conta ou fazer login.

1.2 Instalar

Windows

  1. Execute o .exe
  2. Siga o assistente
  3. Next → Install

macOS

  1. Abra o .dmg
  2. Arraste para Applications
  3. Ejete o volume

Linux

  1. Use o .AppImage
  2. chmod +x Obsidian-*.AppImage
  3. Execute o arquivo
2

Baixar e Extrair o Template

2.1 Baixar o Template

  1. Clique no botão abaixo para baixar o arquivo ZIP
  2. Salve o arquivo em um local de fácil acesso
  3. Depois, siga para a etapa de extração
Baixar Template Grátis

2.2 Extrair o ZIP

Descompacte o arquivo em um local permanente do seu computador. Após extrair, a estrutura será:

📁 Between Notes Starter/
├── 📁 .obsidian/
├── 📁 Atlas/
│   └── 📁 Conceitos/
│       ├── 📁 Onboarding/
│       └── 📁 Referência de Formatação/
├── 📁 Calendar & Review/
├── 📁 Memos/
├── 📁 Projects & Areas/
├── 📁 X/
│   └── 📁 Templates/
└── 📄 Boas Vindas.md
Importante: A pasta .obsidian pode estar oculta. Isso é normal — ela contém as configurações.
3

Abrir o Vault no Obsidian

3.1 Abrir como Vault Existente

  1. Abra o Obsidian
  2. Na tela inicial, clique em Open folder as vault
  3. Navegue até a pasta extraída e selecione-a
  4. Clique em Abrir

3.2 Confiar no Autor

O Obsidian exibirá um aviso sobre plugins de terceiros:

Clique em Trust author and enable plugins. Isso é necessário para ativar Dataview, Templater e os outros plugins incluídos.

3.3 Aguardar Carregamento

O Obsidian vai indexar as notas e ativar os plugins. Isso leva de 5 a 30 segundos. Quando a Homepage carregar, seu vault está pronto.

Pronto!

Seu vault Between Notes está configurado. Abra a nota Boas Vindas para começar o onboarding interativo.

Entrar no Grupo Voltar ao Site

Problemas Comuns

  • Erro ao abrir: Verifique se selecionou a pasta correta (a principal, não uma subpasta)
  • Plugins não carregam: Confirme que clicou em "Trust author and enable plugins"
  • Notas não aparecem: Aguarde a indexação completa (barra de progresso no canto inferior)
  • Erro de permissão: Verifique acesso de leitura/escrita na pasta
